# SICHCP PostgreSQL Docker backup

This package restores the SICHCP PostgreSQL backup into Docker on macOS, Windows, or Linux.

## Requirements

- Docker Desktop installed and running.
- Docker Compose v2, included with current Docker Desktop versions.

## Restore on a MacBook

1. Copy the `SICHCP-postgres-docker` folder to the MacBook.
2. In Terminal, change into that folder.
3. Optionally choose secure credentials and a host port by creating a `.env` file:

   ```sh
   cat > .env <<'EOF'
   POSTGRES_DB=sichcp
   POSTGRES_USER=sichcp
   POSTGRES_PASSWORD=replace-with-a-strong-password
   POSTGRES_PORT=5432
   EOF
   ```

4. Start PostgreSQL and import the backup:

   ```sh
   docker compose up -d
   ```

5. Verify the database is ready:

   ```sh
   docker compose ps
   docker compose exec postgres psql -U sichcp -d sichcp -c "SELECT current_database();"
   ```

Connect from the MacBook with host `localhost`, port `5432`, database `sichcp`, and the user/password selected above. A containerized application should use host `postgres` and port `5432` when it belongs to the same Compose network.

## Important behavior

The SQL backup is imported only when the `postgres_data` volume is first created. To delete all database data and import the backup again, run:

```sh
docker compose down -v
docker compose up -d
```

The source backup was generated by PostgreSQL 18.4 and requires PostgreSQL 18 or newer. It creates the `pgcrypto` extension, which is included in the official PostgreSQL image.
